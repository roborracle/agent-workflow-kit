# UX Research

Transform user insights into actionable design decisions through systematic research methods.

## Research Methods

### Qualitative
| Method | When to Use | Output |
|--------|-------------|--------|
| User Interviews | Deep understanding | Insight themes |
| Contextual Inquiry | Natural environment | Behavior patterns |
| Usability Testing | Validate designs | Issue severity map |
| Card Sorting | Information architecture | Category structure |

### Quantitative
| Method | When to Use | Output |
|--------|-------------|--------|
| Surveys | Large-scale validation | Statistical data |
| A/B Testing | Compare alternatives | Winner + metrics |
| Analytics Review | Current state | Behavior funnels |
| Heatmaps | Visual attention | Click/scroll maps |

## Persona Template
```markdown
## [Name] | [Role]
### Goals: Primary goal, secondary goals
### Frustrations: Pain points
### Behaviors: How they currently solve the problem
### Quote: "Representative quote from research"
```

## Journey Map Components
1. Stages → 2. Actions → 3. Thoughts → 4. Emotions → 5. Pain Points → 6. Opportunities

## Usability Severity Scale
| Severity | Description | Action |
|----------|-------------|--------|
| Critical (4) | Prevents completion | Must fix |
| Major (3) | Significant difficulty | Should fix |
| Minor (2) | Causes frustration | Nice to fix |
| Cosmetic (1) | Noticed but no impact | Consider |

## Insight Format
**Observation**: What we saw/heard
**Insight**: What it means
**Implication**: What to do about it

## System Usability Scale (SUS)
- Score 68+ = above average
- Score 80+ = excellent
- Score 90+ = exceptional
